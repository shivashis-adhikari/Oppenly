The first release of Oppenly: grammar and writing help that stays on your computer.

Oppenly underlines problems as you type, explains each one in a sentence, and fixes it in one
click. Checking runs on your device with the [Harper](https://github.com/Automattic/harper)
grammar engine and Oppenly's own style rules. There is no account, no server and no analytics,
and it works offline.

## What's in this release

| | For | How to get it |
| --- | --- | --- |
| **Browser extension** | Chrome, Edge and Brave | `oppenly-1.0.0-chrome.zip` below |
| **Web app** | A document editor you run on your own computer | The source code below |

## Four kinds of suggestions

| | Checks for | Example |
| --- | --- | --- |
| **Correctness** | Spelling, grammar, punctuation, verb forms, confused words | ~~the results is~~ the results are |
| **Clarity** | Wordy phrases, passive voice, hard-to-read sentences | ~~in order to~~ to |
| **Engagement** | Bland, overused and repeated words | ~~really good~~ excellent |
| **Delivery** | Tone, confidence, politeness, inclusive language | ~~Sorry for the late reply~~ Thank you for your patience |

## Browser extension

- Works in text boxes and rich-text editors on most websites: email, social posts, chats and forms.
- Hover an underline to see the fix and why, then click to apply it. Undo works as usual.
- The Oppenly button in the corner of a text box opens the assistant: every suggestion, "accept
  all" for correctness fixes, rewrites, tone, an overall score and writing goals.
- Select a sentence to make it shorter, more formal, friendlier, more confident or simpler.
- Goals for audience, formality, domain and intent, set once or per site.
- American, British, Canadian, Australian and Indian English, and a personal dictionary.
- Pause it for an hour, or turn it off for a site, from the button or the toolbar icon.
- Keyboard shortcuts: Alt+Shift+O opens the assistant, Alt+Shift+P turns Oppenly on or off for
  the current site.

## Web app

- A full document editor with the same checks, goals and assistant.
- Performance statistics: word count, reading and speaking time, readability and vocabulary.
- Formatting: headings, bold, italic, underline, links, lists and quotes.
- Opens Word (`.docx`), OpenDocument (`.odt`), RTF, Markdown, HTML and plain text files.
- Saves as Word, Markdown, HTML or plain text, or prints to PDF.
- Documents are stored in your browser. Trash, backup and restore are built in.

## Optional AI

Everything above works without AI. If you want context-aware suggestions and full rewrites,
connect your own provider and pay it directly for what you use:

- 17 cloud providers, including OpenAI, Anthropic, Google Gemini, Mistral and OpenRouter.
- Models on your computer: Chrome's built-in AI, Ollama, LM Studio and llama.cpp.
- Any server compatible with the OpenAI, Anthropic or Gemini APIs.

Oppenly asks for your consent before any text is sent, and sends it only to the provider you
chose. API keys are encrypted and stay on your computer.

## Install the extension

1. Download `oppenly-1.0.0-chrome.zip` below and unzip it.
2. Open `chrome://extensions` (in Edge, `edge://extensions`) and turn on **Developer mode**.
3. Click **Load unpacked** and choose the unzipped folder.

A welcome page opens with a short demo. The Chrome Web Store listing is on its way.

## Run the web app

Requires [Node.js](https://nodejs.org/) 22 and [pnpm](https://pnpm.io/installation) 10.

```sh
git clone --branch v1.0.0 https://github.com/shivashis-adhikari/Oppenly.git
cd Oppenly
pnpm install
pnpm web
```

The first run builds the app. It then opens at http://localhost:4870. Keep using that address:
the browser stores your documents for it.

## Good to know

- English only.
- It does not work in Google Docs or in desktop apps yet.
- The extension supports Chrome and browsers built on it, such as Edge and Brave.
- Local checks catch common and medium-level mistakes well. Subtle, context-heavy errors are
  better caught with an AI provider connected.

Four kinds of suggestions

The same categories you may know from other writing assistants, each with its own colour. These examples come straight from Oppenly’s checks.

Correctness

Spelling, grammar and punctuation.

  • Me and Priya Priya and I
  • the results is the results are
  • tommorow tomorrow

Clarity

Wordy phrases, passive voice and hard-to-read sentences.

  • in order to to
  • make a decision decide
  • The report was written by the team The team wrote the report

Engagement

Bland, overused and repeated words.

  • really good excellent
  • very important crucial
  • very bad terrible

Delivery

Tone, confidence and politeness, tuned to your goals.

  • Sorry for the late reply Thank you for your patience
  • I was wondering if you could Could you
  • Hey guys Hi everyone

Every suggestion in one place

Click the Oppenly button in the corner of a text box to see all suggestions for it. Accept every spelling and grammar fix at once, or go through them one by one. The Insights tab shows the tone of your text, reading time and an overall score.

Rewrite a sentence

Select text to shorten it or make it more formal, friendlier or more confident. These rewrites run on your device. Connect an AI provider to add options like “improve”, “expand” and your own instructions.

Off when you want it off

Pause Oppenly for an hour, turn it off on one site or everywhere, straight from the button in the text box. It stays out of code editors and password fields.

Your writing stays yours

Most writing assistants send everything you type to their servers. Oppenly doesn’t have servers.

Checked on your device

The grammar engine and Oppenly’s style rules run inside your browser. Your text is never sent anywhere to be checked.

No account, no analytics

There is nothing to sign up for. Oppenly collects no usage data, sets no cookies and shows no ads.

AI only if you ask for it

Connect an AI provider with your own key, or a model on your computer. Oppenly asks for your consent first and sends text only to the provider you chose.

Open source

All of the code is public under the Apache 2.0 license, so anyone can check these claims.

A full editor, on your machine

The Oppenly web app is a document editor with the same checks, plus goals, performance stats, formatting, and Word, OpenDocument and Markdown import and export. It runs from the source code on your own computer and keeps documents in your browser.

Run it

Needs Node.js 20 or later and pnpm. Then open http://localhost:4870. 

git clone https://github.com/shivashis-adhikari/Oppenly.git
cd Oppenly
pnpm install
pnpm web

Questions

Is Oppenly really free?

Yes. There is no paid plan, no ads and nothing to sell. If you connect a cloud AI provider, that provider bills you directly for what you use.

Does it work offline?

Yes. Checking and the built-in rewrites work without an internet connection. Only cloud AI providers need one.

Where does it work?

In text boxes and rich-text editors on most websites: email, social media, chat, forms and content tools. It does not work in Google Docs yet, because Google Docs draws text in its own way and only allows approved extensions to read documents.

Which languages does it check?

English, in American, British, Canadian, Australian or Indian spelling.

What does an AI provider receive?

Only the text you check or rewrite and instructions for the task, sent with your key to the address you set up. Nothing else from the page or your browser. You can remove a provider at any time.

Which browsers are supported?

Chrome, and browsers built on it such as Microsoft Edge and Brave. The web app runs in any modern browser.
